ℹ️ About This Analysis

This page correlates Tonal strength volume with Garmin running pace to explore whether strength training improves running economy. Because Tonal data currently ends in April 2025 and Garmin data starts February 2025, the overlap window is limited. As more concurrent data accumulates, the correlation will become more meaningful.

Note: All Tonal workouts are included (not filtered by muscle group) since muscle group metadata is not available in the raw export. Volume is in lbs as reported by Tonal (totalVolume field, no conversion needed).
